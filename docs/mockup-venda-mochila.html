Variante 1: lista pura, com ferramentas para a lista grande

  1. Dois grupos em vez de uma lista corrida. "Vende" em cima, com o que a próxima viagem leva e o gold estimado; "Fica" embaixo, recolhido. Com 60 itens você vê 20 linhas, não 60.
  2. Busca filtra na hora. Busca + "Marcar visíveis" marca uma família inteira de itens (ex.: digitar "gem") sem clicar um a um.
  3. Filtros: Loot (só o que o Mark compra sem aviso), ⚠ Atenção (raros, pedras, outras categorias), Novos (apareceu na mochila desde a última leitura: é o item da daily que você nunca marcou).
  4. Ordem por valor (quantidade × preço) traz para cima o que pesa no gold; por quantidade mostra o que está acumulando.
  5. "Manter" só aparece em quem está marcado, como hoje. O campo é estreito para não quebrar a linha nos 400 px.
  6. 🔒 em cinza = não dá para marcar, com o motivo: lista da família, item da guild/clã/farm/mercado/boss/invasão, cadeado do jogo, preço 0.
  7. Botão Ler mochila pede o frame inventory pelo socket (o que o jogo faz ao abrir a bolsa): funciona na hunt. O script também lê sozinho antes de cada viagem.

Esta variante guarda exatamente o que você marcou: sellItems = { id: { keep } }, uma lista só por conta. Item novo que cair numa hunt nova NÃO entra sozinho: aparece em "Fica" com a etiqueta "novo" até você marcar.

Variante 2: a mesma lista, com uma regra por baixo

  1. Um interruptor resolve o grosso: "vender todo drop comum" marca sozinho tudo que é categoria loot e não é raro. Nas suas 4 contas é exatamente isso que você marca hoje (Earth Ball, Sandbag, Small Stone, Stone Orb, Bug Gosme, Seed, Straw…).
  2. A caixinha sempre mostra o que vai acontecer. Desmarcar um item que a regra cobre vira "exceção" (nunca vende); marcar um raro vira "marcado". Não existe terceiro estado escondido.
  3. Raros e pedras continuam opt-in: Pinsir Horn, Scythe, Helix Fossil, Lizard Tail e as stones só vendem se você marcar, como hoje. O que a regra não cobre fica em "Fica" com ⚠.
  4. Item novo de daily/guild/invasão entra sozinho se for loot comum. Era o problema de origem: a conta muda de hunt e ninguém marca o drop novo.
  5. Regra desligada = a variante 1, sem perder as marcações.

Config: sellRule: true, sellItems = { id: { keep } } (marcados na mão) e sellNever: [ids] (exceções). A lista da família e os itens que outro módulo segura vencem a regra sempre.

Minha recomendação: a variante 2. A lista grande deixa de ser um problema porque você não precisa clicar nela: a regra marca o comum, a busca e os grupos servem para conferir e abrir exceções. Para as 4 contas a migração é automática: a união dos perfis vira os "marcados", o resto do loot comum entra pela regra.
